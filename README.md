
# 🪨 Stone, Paper, Pencil Game

A simple Python command-line game where you play against the computer in 3 rounds.

## 🎮 How to Play
- Enter `s` for Stone
- Enter `p` for Paper
- Enter `c` for Pencil
- The computer randomly chooses its move.
- The winner of each round is decided by the game rules.

## 🛠️ Built With
- Python
- Random module

## ▶️ How to Run
1. Install Python.
2. Download or clone this repository.
3. Run the following command:

   ```bash
   python game.py
   ```
